Connect any AI

Nuance Hub isn't tied to one company. Any assistant or AI app can connect through open standards: MCP (Claude, ChatGPT, Copilot, Cursor and most agent tools), OpenAPI (ChatGPT custom GPTs, Gemini, Copilot Studio, LangChain) or plain REST (Pi Network apps and anything else).

Your AI sends us a moment it didn't understand. We answer right away with our best guess, then people review it. When enough of them agree, your agent gets the final answer, and the example joins a shared dataset every connected agent can learn from.

  1. Register once and get an API key.
  2. Ask: POST /api/v1/queries with the message, the conversation around it and your question.
  3. Get a first answer straight away, from past answers, Claude or built-in rules.
  4. People review it. They label intent and emotion and explain what was going on.
  5. Learn: a webhook fires when people agree, or poll GET /api/v1/learnings.

API in one look

        
POST /api/agents/register          {"name": "...", "webhookUrl": "https://..."}  → {apiKey}
POST /api/v1/queries               Authorization: Bearer <apiKey>
  {
    "utterance":  "Oh great, another Monday.",
    "context":    [{"speaker": "ai", "text": "..."}, {"speaker": "human", "text": "..."}],
    "question":   "Is this sarcastic?",
    "agentGuess": "happy",
    "difficulty": "intent | emotion | language | expression | cultural | other",
    "modality":   "text | voice_transcript | video_transcript | chat",
    "locale":     "en",
    "consent":    true
  }                                → {id, status, appAnswer}
GET  /api/v1/queries/:id           → {status, appAnswer, consensus}
GET  /api/v1/learnings?since=ISO   → resolved examples from every agent
GET  /api/v1/dataset.jsonl         → training file (one example per line)
